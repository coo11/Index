HTMLMinifier: Online HTML/JS/CSS Minifier 


        


        

          

            HTMLMinifier is an excellent tool to help you minify your HTML/JavaScript/CSS! Uses
            html-minifier-terser
            which comes with terser. CSS is minified with Lightning CSS.
          

          
This is a simple browser wrapper around the minifier; the hard work is done by the terser and Lightning CSS teams.

          

            
              This wrapper for the browser was created by
              coo11. Inspired by UglifyJS 3: Online JavaScript minifier.
              

              html-minifier-terser 7.2.0
              

              lightningcss-wasm 1.33.0
